# md_viewer_java
Markdown ファイルおよびフォルダをブラウザで閲覧するための簡易ビューア。  
Tomcat 11（Jakarta EE 10）環境で動作し、複数の Markdown をタブ形式で表示できる。

---

## 📦 機能概要

- フォルダまたは複数の `.md` ファイルをアップロード可能
- アップロードされた Markdown を HTML に変換して表示
- 複数ファイルをタブ形式で切り替え可能
- タブの削除機能あり
- iframe により複数 Markdown を同時表示
- UTF‑8 完全対応（JSP / Servlet / HTML）
